# Code of conduct

Be kind and be specific. Disagree with the work, not the person. Earthquakes hurt real people, so keep
discussion of any event factual and respectful of those affected.

Harassment, personal attacks and spam are not welcome in issues, pull requests or discussions. The
maintainer may edit or remove comments, close threads and block accounts that break this rule.

To report a problem, open an issue that does not name anyone, or email the address on the maintainer's
GitHub profile.
